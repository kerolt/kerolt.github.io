RockyLinux启用EPEL软件仓库

2026年1月26日 · 1 分钟 · Kerolt

epel-release 是一个 RPM 软件包，用于在基于 Red Hat 的 Linux 发行版（如 RHEL、CentOS、Rocky Linux、AlmaLinux 和 Oracle Linux）上启用 EPEL（Extra Packages for Enterprise Linux） 软件仓库。

EPEL 是一个由 Fedora 项目维护的社区驱动的额外软件包仓库，提供不在标准 RHEL 或其衍生发行版基础仓库中的高质量开源软件包。

通常安装方法如下：

1
2

sudo dnf install epel-release -y
sudo dnf makecache
